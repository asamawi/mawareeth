- (decision) Usability: add heirs with one press or drag-and-drop instead of radio + name + save
- (decision) Usability: opening a saved case must not show the start/resume/start-over interstitial; cases get editable names instead of case references
- (decision) Usability: do not label result 'Calculated under the Hanbali school' when all schools agree
- (decision) Usability: edit and delete heirs directly from the family tree
- (decision) Usability: 'see full result' must be a prominent control, not a text link under the table
- (decision) Languages: add languages of Muslim communities, candidates Indian languages, Urdu, Chinese, German, Spanish, Italian and other European
- (decision) Out of scope: paid reviewed calculation stays in the private marketplace project
- (decision) Indian languages: Hindi first; other Indian languages (e.g. Bengali, Tamil, Malayalam) may follow
- (decision) Stakes launch-grade; working mode fast path
- (decision) Country presets in phase 2: Saudi Arabia, UAE, Egypt, Jordan, Morocco, Algeria, Lebanon (Lebanon added by owner; not covered by research)
- (decision) New languages in phase 2: Urdu, Hindi, Turkish, Indonesian, Malay, German, Spanish, Italian, Chinese
- (decision) Support: contact form creating tracked tickets followed by email, plus WhatsApp click-to-chat
- (decision) Review model: AI drafts translations and content; owner reviews; no outside scholar/translator sign-off this phase (overrides research recommendation of jurist sign-off per preset)
- (decision) Lebanon preset covers Sunni (Hanafi-based) law only; Ja'fari deferred to a later phase; needs a short research pass
- (decision) Unreviewed country presets and AI-translated languages carry a visible beta / not-yet-reviewed label plus disclaimer until outside review
- (decision) Success signals: fewer steps per case, higher share of started cases reaching a result, reach in preset countries and new locales, support responsiveness
- (event) Fast-path draft written: prd.md (30 FRs, 6 UJs, 8 features) and addendum.md (preset settings, data shape, ticketing options)
- (change) Lebanon research done: Lebanon Sunni preset = Hanafi, no obligatory bequest; addendum §A and PRD open question 1 and §4.4 notes updated
- (decision) AI-friendly = AI tools can use Mawareeth: public calculation API + OpenAPI + MCP server + prefilled case links + fair use (FR-31 to FR-35, UJ-7, SM-6, SM-C4). Not chosen: chat case entry, AI search optimisation, AI result explainer
- (decision) API: commercial apps may use free API within the limit; above it they pay. Heavy users request billable API keys via a Ticket (FR-36); billing manual in phase 2 (assumption)
